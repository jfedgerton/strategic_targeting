## Hardest cases

1. **146 Navarino 1827.** The treaty's stated motive mixes humanitarian language ("effusion of blood", which reads like b) with commerce, piracy and an operative aim of Greek autonomy (a secession settlement). The rule requires a single main justification, and the text does not give one.
2. **135 Mexico 1861.** Debt suspension was the trigger, but official texts frame it as redress for "wrongs ... upon Foreigners", which reads like c. I coded the main aim as debt collection. A coder who reads "outrages on persons" as primary would code borderline or c. The 3-state count is also doubtful, since only France fought.
3. **3058 Grenada 1983.** Protection of nationals is first among three reasons, but restoring order and government institutions at the OECS's request is close to co-equal. The restoration exclusion does not formally apply because the deposed regime was unelected.
4. **611 Vietnam.** Whether "aggression from the North" (a) or the SEATO commitment (an alliance-war aim) is the main public justification depends on period and speaker.
5. **3552 and 4273 (Iraq).** The b-versus-d trigger choice does not change the result, but the supplied counts look inflated by Saudi Arabia, which hosted rather than used force. For 4273, combining Desert Fox and the 2003 invasion in one MID means two different coalitions share one code.
6. **2150 Shaba I and 145 Nanking.** The triggers are clear, but the supplied counts appear inflated: Uganda and CAR for Shaba, Japan and France for Nanking.
