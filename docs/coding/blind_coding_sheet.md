# Blind coding sheet — history-chosen exclusions (independent coder)

Code each case under the rule below **without** consulting the project's results, lists or prior codings (do not open `docs/historical_exclusions.md`, `inputs/exclusions_*.txt`, `docs/decisions.md`, any output, or the memory/results ledger). Use contemporaneous primary sources where possible and cite one per case.

## Rule
1. Closed list of triggers. The coalition's main public justification at the time is one of: (a) aggression by the target against another state; (b) mass atrocities; (c) attacks on foreign nationals or diplomats; (d) defiance of UN Security Council resolutions; (e) an attack by the target state or by forces it harbours. Restoring an elected government is not a trigger.
2. Main justification. A qualifying rationale counts only if it was the main public justification at the time; territorial, colonial, succession, debt-collection and alliance-war aims as the main aim exclude the case.
3. Three states using force in the dispute (count supplied from COW-MID participant data; flag if history contradicts it).
4. UN-authorized: the Security Council authorized or recommended force for that operation (recognition of self-defense or demands without a force mandate do not count).

## Output (one row per case)
| Dispute | Qualifies (yes / no / borderline) | Trigger letter or exclusion reason | UN-authorized (yes/no) | Confidence | Source (URL) | Note |
